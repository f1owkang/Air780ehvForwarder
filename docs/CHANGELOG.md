# 更新日志

## v1.4.0 (2026-09-08)

### 新功能

- **Qbot 按钮回调**：指令按钮升级为回调按钮（type=1 + INTERACTION_CREATE），点击直达后台、不在会话里留下指令文本；点击后立即回应回调（否则客户端一直 loading），结果用 event_id 被动回复，不占主动配额
- **Qbot 生命周期事件补订**：FRIEND_DEL（用户删好友→暂停对其推送）、C2C_MSG_REJECT/RECEIVE（用户开关主动消息→自动暂停/恢复 pushToUser）、GROUP_MSG_REJECT/RECEIVE（群管理员开关→同上），避免无效推送静默浪费配额
- **供电电压监控**：周期读取 VBAT（默认 10 分钟），低于阈值（默认 3.5V）走备用通知告警（每小时最多一条）；「状态」指令新增电源行，信号行补充 RSRQ/SNR。配置：`BAT_MONITOR / BAT_LOW_MV / BAT_CHECK_INTERVAL`
- **短信编码兜底**：检测到短信内容非合法 UTF-8（部分运营商下发 GBK/GB2312 会乱码）时，自动用 iconv 转码（101 号固件内置），全 pcall 保护不影响正常短信

### 修复

- **定时器回调 sys.wait 协程违规（两处）**：定时重启与 Qbot 指令重启此前会在非协程上下文抛错导致重启不生效，统一改为发 DEVICE_RESTART 事件、由常驻重启协程完成清理与复位
- **备用通知 fskv 持久化只写不读**：补上电恢复（遍历 fskv 重建队列，兼容旧版纯文本格式）、放弃重发时清理孤儿键，键不再只增不减
- **HTTP 异常时网络 LED 永久快闪**：util_http.fetch 全路径 pcall 保护，计数必定归位
- **SMTP 任务名同秒撞名**：os.time() 改为自增序号，转发与备用通知的并发邮件不再冲突
- **备用通知静默丢弃**：渠道返回 nil（未配置/内部异常）从"视为成功"改为进入重试并最终清理；默认备用渠道从写死 feishu 改为自动挑选第一个已配置渠道
- **短信控制号码正则不一致**：拆分正则统一为 5~20 位校验，5 位短号不再被误杀
- **跨模块隐式全局依赖**：util_forward/util_notify/util_channel 补显式 require（qq 渠道保留运行期惰性加载防循环）
- **基站定位任务永久挂死**：CELL_INFO_UPDATE 等待加 30 秒超时兜底
- **转发路径 errcode 漏判**：企业微信（-1/45009）、钉钉（-1/410100 限流、310000 时间戳过期）200 但 errcode 非 0 时判为失败；飞书转发补加签（与备用通知能力对齐）
- **config.lua 缺失时 rtos.restart 返回会继续跑**：改为原地挂死并持续报错

### 优化

- util_forward 匹配循环与转发任务骨架去重（matchRules/dispatchRules 公共函数）
- 原生菜单/按钮之外无其他变更

## v1.3.1 (2026-09-08)

### 体验优化

- **指令菜单统一排版**：帮助菜单由 `COMMANDS` 指令表自动生成（指令表即唯一数据源，不再重复维护）；指令名按显示宽度（CJK 计 2 格）全角空格补齐对齐，呈整齐两列
- **全部回复卡片风格统一**：规则列表、重启确认、欢迎引导、最近短信均改用与「状态」相同的加粗标签 + 全角空格排版，页脚统一一行提示
- **三端一致**：按钮键盘（8 键两行）与原生菜单顺序对齐帮助菜单分组（查询 → 短信 → 控制，重启置灰置底）

## v1.3.0 (2026-09-08)

### 新功能

- **Qbot 交互通道**：设备直连 QQ 官方机器人（无需服务器），在 QQ 单聊或群 @机器人 即可下发指令
  - 基于 LuatOS websocket 库实现 API v2 网关协议（Access Token 鉴权、IDENTIFY/RESUME、心跳保活、指数退避重连）
  - 指令：帮助 / 状态 / 短信 [N] / 重载规则 / 测试 / 发短信 号码 内容
  - 指令系统升级为表驱动：新增 信号/设备/定位/流量/时间/规则/飞行模式/重启(二次确认)；帮助菜单按分组自动生成
  - 输入体验：全角自动转半角、/ 前缀容忍、群聊 @前缀剥离、空输入(只@)返回菜单、未知指令前缀建议
  - openid 白名单防未授权操控；非白名单用户自动回复欢迎消息（含其 openid 与配置指引），每 openid 最多 3 次防刷；REST 请求强制域名白名单与 URL 校验
  - 新增 `util_sms_store.lua`：fskv 持久化的最近短信环形缓存（20 条，断电不丢）
  - 配置项：`QQBOT_ENABLED / QQBOT_APPID / QQBOT_SECRET / QQBOT_ALLOW`
  - 短信通知仍走转发规则渠道；如需推送到 QQ，使用下方 qq 转发渠道

- **QQ 推送渠道**：转发规则新增 `channel = "qq"`，短信可主动推送到 QQ 单聊（`openid`）或群（`group_openid`）
  - 仅依赖 Access Token，wss 断连不影响推送，与 webhook 渠道互为备份
  - 官方频控：每好友/每群 20 条/分钟、1000 条/天

### 安全修复

- `SMS,号码,内容` 短信控制指令增加管理员号码白名单 `SMS_ADMIN_NUMBERS`（空表全部拒绝；修复任意发件人均可触发设备发短信、消耗话费的问题）

### 规范化

- 配置模板化：仓库内 `config.lua` 更名为 `config.example.lua`，本地实际 `config.lua` 加入 `.gitignore`（真实凭据不入库）；缺少 config.lua 时启动即报清晰错误提示
- 移除无效配置项 `NETWORK_TIMEOUT_LOCATION`（全项目无代码引用；经全量比对 38 个配置键中唯一死配置）
- 源代码统一移入 `script/` 目录（Luatools 烧录直接选择该文件夹）；文档与硬件手册收拢至 `docs/`，根目录仅保留 README / AGENTS / LICENSE
- 采用 Apache 2.0 协议（与 GitHub 仓库一致）；上游 air780e_forwarder 为 MIT，其版权声明在 README 致谢中保留
- 表述统一：文档/注释/日志中"QQ 机器人"简化为 **Qbot**（代码标识符 `QQBOT_*`、`util_qqbot`、渠道名 `qq` 不变）
- 代码清洁：删除过时的 AGENT.md（以 AGENTS.md 为准）；移除 `util_notify` 无实际功能的 storage 占位任务；备用通知配置键（`FEISHU_WEBHOOK` 等）并入 `config.lua` 第 5 节（默认留空）
- 配置集中化：所有用户配置合并到 `config.lua` 单文件，分五节（系统与网络 / Qbot / 短信控制安全 / 转发规则 `FORWARD_RULES` / 备用通知），移除 `config_forward.lua`
- 新增 `POWERKEY_PIN` 配置项：`pin_table` 未收录的平台（如 Air780EHV）可直接在配置中指定电源键引脚，无需改代码
- 文件更名：`forward_config.lua`→`config_forward.lua`（后并入 config.lua）、`task_manager.lua`→`util_task.lua`、`util_notify_channel.lua`→`util_channel.lua`
- 命名规范统一：入口 `main.lua`，配置 `config.lua`，模块 `util_*.lua`；main.lua 全局 `TaskManager` 更名为 `util_task`
- `PROJECT` 更正为 `air780ehv_forwarder`（与实际芯片一致）

### Bug 修复

- 修复 LuatOS 固件 `tonumber(nil)` 直接抛错导致的问题：未收到短信时 `状态` 指令崩溃；**首条短信会使回调中断、影响转发**——短信缓存读写改为类型检查读取，`save()` 整体 pcall 包裹，缓存故障不再影响转发主流程
- token 有效期解析增加类型防御

### 新功能（v1.3.0 续）

- **Qbot markdown 回复**：新增 `QQBOT_MARKDOWN` 配置（默认关闭），开启后菜单/状态等回复以 markdown 格式发送（标题与分组加粗）；机器人无 markdown 权限时自动回退纯文本并本次会话记住
- **生命周期欢迎**：新好友添加自动私信欢迎（含 openid 与配置方法）；机器人进群自动问候（event_id 被动回复，说明 @指令 与白名单）；退群记录日志；欢迎额度共用防刷
- **指令合并**：`状态` 升级为一屏全览卡片（信号/网络/时间/定位/设备标识打码/内存/规则/缓存），移除独立的 信号/设备/定位/时间 指令；手机号与 IMEI 群聊场景打码展示
- **菜单重设计**：按 QQ markdown 官方语法重排（分组加粗标题 + 正确空行的列表 + 引用提示行，修复列表前缺空行不渲染的问题）；帮助按钮分主次两色（蓝框常用/灰框危险操作）
- **原生菜单**：Qbot 连接成功后自动 `PUT /v2/menu` 注册单聊窗口底部官方菜单（状态/短信/规则/更多▾），`QQBOT_MENU` 可关（默认开）
- **按钮权限修复**：键盘按钮 `permission` 改为所有人可点（`type=2`），修复指定用户（`type=0`）在部分客户端点击报"无权限操作"的问题；安全仍由指令层 openid 白名单把关
- **emoji 克制化**：移除装饰性 emoji（每行图标/问候图标等），仅保留 ✅/❌/⚠️ 三类语义符号；状态卡片改用加粗标签排版，菜单去图标靠分组加粗 + 列表 + 引用行；`取消` 指令与 `确认` 成对（撤销待确认操作）
- **按钮键盘**：新增 `QQBOT_BUTTONS` 配置，指令菜单附带 8 个常用指令按钮、重启确认附带「确认/取消」按钮（点击即发送指令，仅发起人可点）；欢迎消息配置行以代码框渲染；发送失败逐级降级（md+按钮 → 纯 md → 纯文本）
- **markdown 默认开启**（`QQBOT_MARKDOWN = true`）：无权限回退纯文本时自动去除 `**`/`` ` `` 样式符号，避免显示乱码

## v1.2.0 (2026-04-09)

### 新功能

- **SMTP邮件转发**：新增邮件转发渠道（`channel = "email"`），支持将短信转发到指定邮箱
  - 支持 SSL/TLS 加密连接（端口 465），适用于QQ邮箱、163邮箱、Gmail等主流邮箱
  - 支持明文连接（端口 25），适用于内网邮件服务器
  - 邮件标题和正文支持 UTF-8 编码
  - SMTP配置写在每条转发规则中，支持不同规则转发到不同邮箱
  - 使用 AUTH LOGIN 认证方式
